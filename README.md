2. **قائمة الموديولات الكاملة (16 موديول)**: الحسابات، المبيعات، المشتريات، المخازن، القبض والصرف، كاشير POS، تطبيق مندوب المبيعات، ربط المتجر الإلكتروني، الأصول الثابتة، الموارد البشرية والرواتب، CRM، إدارة المشاريع والمقاولات، التصنيع (`BOM`)، بوابات الدفع، النسخ الاحتياطي اليومي، والتقارير غير المحدودة.
3. **موسوعة الأنشطة التجارية الشاملة (18 قطاعاً جاهزاً)**: أكثر من **144 صنفاً مكوداً** بمسمياتها ووحداتها وحساباتها التخصصية (مقاولات، مصانع، سوبر ماركت، صيدليات، مطاعم، ملابس، موبايلات، قطع غيار، حدايد وبويات، أثاث، ذهب، أعلاف، مكتبات، عطارة، أجهزة منزلية، عيادات، سيراميك، حلويات، استيراد وتصدير، ومغاسل).
4. **ماسح الباركود الحي ثلاثي المحركات + كشاف الموبايل (📷🔦)**:
   - يدعم البث المباشر `WebRTC getUserMedia` مع الفوكس المستمر وفتح الكشاف الخلفي (`Torch`).
   - مزود بجسر **بث الفيديو الحي (`Live Video Stream Bridge`)** للعمل حتى عند فتح الملف محلياً عبر `content://` على أندرويد.
5. **محرك الفواتير `PDF` واستوديو الملصقات `PNG` (100% أوفلاين)**:

## 🚀 خطوات النشر السريع على GitHub Pages (لتفعيل رابط HTTPS والكاميرا الحية)

1. أنشئ مستودعاً جديداً على GitHub وارفع ملفات هذه الحزمة إليه.
2. من تبويب **Settings** في المستودع، افتح قسم **Pages**.
3. تحت **Build and deployment**، اختر **Deploy from a branch** وحدد الفرع `main` والمجلد `/ (root)` ثم اضغط **Save** (أو اختر **GitHub Actions** ليقوم ملف `deploy-pages.yml` بالنشر تلقائياً).
4. خلال ثوانٍ سيعمل تطبيقك عبر الرابط الآمن `https://<username>.github.io/<repository-name>/` بكامل صلاحيات الكاميرا الحية والتثبيت الأوفلاين على الهاتف والكمبيوتر.
